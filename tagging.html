How Azure applies tags

  • Tags are key-value pairs attached to an Azure resource for ownership, governance, reporting, and cost management.
  • The JSON above contains only the tags you selected, so it can be merged into an existing resource definition.
  • Apply tags at deployment time where possible, or use Azure Policy to enforce required keys and approved values consistently.
  • Tag values are case-sensitive in this standard. Keep the key names exactly as shown.
az resource tag --tags key=value another-key=another-value
